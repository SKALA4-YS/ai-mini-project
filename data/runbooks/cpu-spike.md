# Runbook: CPU 급증 대응 절차

## 대표 증상
CPU 사용률이 평소보다 급격히 높아지고 임계치(80%)를 넘어 지속된다. 특정 인스턴스가 연산 부하로 느려지고, 트래픽 증가·배포 직후·배치 중복 실행과 함께 나타나는 경우가 많다. 키워드: CPU 급증, CPU 100%, 연산 부하, 스로틀링, load average 상승.

## 대응 절차
1. get_monitoring_status로 CPU 사용률과 최근 배포/트래픽 변화 시점을 확인한다.
2. 반복 호출, 배치 작업 중복 실행 같은 특정 요청 패턴이 원인인지 최근 로그에서 확인한다.
3. CPU가 90%를 넘고 지속되면 해당 인스턴스를 오토스케일링 그룹에서 한 대 더 띄워 부하를 분산한다.
4. 급증이 특정 배포 직후 시작됐다면 직전 배포를 롤백하고 원인 분석은 별도로 진행한다.
5. 정상화 후 프로파일링 결과를 바탕으로 핫스팟 코드를 식별해 최적화 작업을 등록한다.
